Prüfblatt für die Registerkarte „Issues"

Diese Seite trägt zwei Eingabefelder. Eines hat weder id noch name, das andere hat beides.

So wird gemessen:

  1. Entwicklerwerkzeuge öffnen (F12).
  2. Diese Seite neu laden (F5), während sie offen sind.
  3. Registerkarte „Issues" ablesen.

Erwartet: genau ein Eintrag — „A form field element should have an id or name attribute", und er muss auf Feld A zeigen.

  • 1 Eintrag → das Werkzeug sieht hin. Dann ist eine Null auf einer Panelseite eine Aussage über die Seite.
  • 0 Einträge → das Werkzeug meldet diese Art in dieser Browserfassung nicht. Dann ist jede Null auf einer Panelseite keine Messung, sondern ein Schweigen.
  • 2 Einträge → unerwartet; dann bitte beide Wortlaute abschreiben.

Dazu die Fassung des Browsers: chrome://version, erste Zeile.
