# repo.cloudsrv24.de

Dieser Zweig ist die veröffentlichte Seite von **SrvPanel** — Startseite,
Installationsskript und die apt-Paketquelle. Er wird vom Freigabelauf
geschrieben und nicht von Hand gepflegt; Änderungen gehören nach
`packaging/` im Hauptzweig.

- Quelltext, Fehler und Beiträge: <https://github.com/philf90/Server-Control-Panel>
- Lizenz: AGPL-3.0-only (siehe `LICENSE`)

Der Inhalt hier stammt aus `packaging/pages/`, `packaging/install.sh` und
`packaging/php-source.sh`. Wer eine Datei hier von Hand ändert, verliert die
Änderung mit der nächsten Freigabe.
