Prüfblatt 2 — welche Arten meldet dieser Browser?

Acht Bedienelemente, keines mit id oder name. Jedes trägt stattdessen eine Klasse, an der man es im Reiter „Elements" wiedererkennt.

So wird gemessen: Entwicklerwerkzeuge öffnen (F12), diese Seite neu laden (F5), Registerkarte „Issues", den Eintrag „A form field element should have an id or name attribute" aufklappen und unter AFFECTED RESOURCES die Zahl ablesen.

Wer wissen will, welche gemeldet sind: jeden Violating node anklicken — im Reiter „Elements" steht dann die Klasse art-… des getroffenen Elements.

Ablesungwas sie sagt
8Dieser Browser meldet jede Art. Dann ist eine Null auf einer Panelseite eine Aussage über die Seite.
weniger als 8Er meldet nur einen Teil. Dann sagt die Liste der Klassen, welchen — und eine Panelseite, die nur die übrigen Arten trägt, schweigt zu Recht.
0Widerspricht Prüfblatt 1 und wäre selbst ein Befund.
