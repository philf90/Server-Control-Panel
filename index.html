SrvPanel

Kunden · Abonnements · Web · PHP · Datenbanken · DNS · Dateien · Sicherungen

Hosting-Panel für einen einzelnen Linux-Server, vergleichbar mit Plesk: Der Betreiber verwaltet Kunden, Kunden verwalten ihre Abonnements — ohne SSH und ohne Zugriff auf fremde Daten. Ein Systembenutzer je Abonnement.

Vorabversion 0.6.0-rc.18. Anmeldung mit zweitem Faktor, Kunden und Abonnements als Datenmodell, Rechte und Mandantentrennung, Protokoll mit Export, Vorgänge mit Live-Ausgabe und Abbruch, Adminübersicht mit Kennzahlen. Was noch fehlt, ist alles, wofür man ein Panel kauft: Websites, Datenbanken, DNS, Postfächer, Sicherungen. Für den Betrieb echter Kunden ist das noch nichts.

Installieren

curl -fsSL --proto '=https' --tlsv1.2 https://repo.cloudsrv24.de/install.sh -o install.sh
sudo SRVPANEL_CHANNEL=beta sh install.sh

Das Skript richtet die Paketquelle ein, besorgt PHP 8.4 und installiert daraus. Um die PHP-Quelle muss sich auf diesem Weg niemand kümmern — wer stattdessen von Hand über apt geht, braucht dafür srvpanel-php-source, siehe unten.

Danach einmal sudo srvpanel setup: Das legt Datenbank, Anwendungsschlüssel und ein selbstsigniertes Zertifikat an, schreibt den nginx-Server-Block und startet die Dienste. Der Lauf ist wiederholbar und wechselt dabei keinen Schlüssel.

Über apt

sudo curl -fsSL --proto '=https' --tlsv1.2 \
  https://repo.cloudsrv24.de/apt/srvpanel-archive-keyring.gpg \
  -o /usr/share/keyrings/srvpanel-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/srvpanel.sources >/dev/null <<'EOF'
Types: deb
URIs: https://repo.cloudsrv24.de/apt
Suites: beta
Components: main
Signed-By: /usr/share/keyrings/srvpanel-archive-keyring.gpg
EOF
sudo apt update && sudo apt install srvpanel-php-source
sudo apt update && sudo apt install srvpanel

srvpanel-php-source ist auf diesem Weg Voraussetzung, nicht Zubehör. Ohne es endet der zweite Befehl mit „php8.4-cli ist aber nicht installierbar" — einer Meldung, die die Ursache nicht nennt.

Zwei Schritte, und der erste ist keine Umständlichkeit: Das Panel braucht PHP 8.4, und das liefern Debian 12, Ubuntu 22.04 und 24.04 nicht aus eigenen Quellen. srvpanel-php-source trägt deb.sury.org ein — als eigenes Paket, weil apt die Abhängigkeiten eines Pakets auflöst, bevor dessen Skripte laufen. Ein srvpanel, das die Quelle selbst nachreichte, käme immer zu spät. Auf Debian 13 ist PHP 8.4 im Bestand; dort tut das Paket nichts.

Solange nur Vorabversionen erschienen sind, liegt das Paket ausschließlich im Kanal beta. Der Kanal stable bekommt es mit der ersten Fassung ohne Bindestrich in der Version.

Der Vorgänger

Bis 0.6.2 hieß dieses Repository Project Asylum — ein schlankes Control Panel als einzelnes Go-Binary. SrvPanel ist ein Neubau, kein Nachfolger im Sinne eines Updates: andere Sprache, anderes Datenmodell, kein Migrationspfad. Bestehende Installationen laufen unter dem Paketnamen asylum-panel im Kanal stable weiter; ihr Quellstand liegt im Branch legacy/asylum.
